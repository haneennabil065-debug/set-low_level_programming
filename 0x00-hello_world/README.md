# 0x00. C - Hello, World

This project introduces the C programming language and the compilation process.

## Tasks

- 0-preprocessor: Runs the C preprocessor.
- 1-compiler: Compiles a C file without linking.
- 2-assembler: Generates assembly code.
- 3-name: Creates an executable named cisfun.
- 4-puts.c: Prints a message using puts.
- 5-printf.c: Prints a message using printf.
- 6-size.c: Prints the sizes of different data types.
