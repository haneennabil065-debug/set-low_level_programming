# 0x05. C - Pointers, arrays and strings

This project contains C exercises about pointers, arrays and strings.

## Files

- `main.h` - header file with all function prototypes
- `_putchar.c` - writes a character to stdout
- `0-reset_to_98.c` - updates the value of an int to 98 using a pointer
- `1-swap.c` - swaps the values of two integers
- `2-strlen.c` - returns the length of a string
- `3-puts.c` - prints a string followed by a new line
- `4-print_rev.c` - prints a string in reverse
- `5-rev_string.c` - reverses a string
- `6-puts2.c` - prints every other character of a string
- `7-puts_half.c` - prints the second half of a string
- `8-print_array.c` - prints n elements of an array of integers
- `9-strcpy.c` - copies a string to a buffer
