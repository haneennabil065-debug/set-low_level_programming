# 0x04. C - More functions, more nested loops

This project covers functions, nested loops and basic output in C.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all the function prototypes |
| `_putchar.c` | Writes a character to stdout |
| `0-isupper.c` | Checks for an uppercase character |
| `1-isdigit.c` | Checks for a digit (0 through 9) |
| `2-mul.c` | Multiplies two integers |
| `3-print_numbers.c` | Prints the numbers from 0 to 9 |
| `4-print_most_numbers.c` | Prints the numbers from 0 to 9, except 2 and 4 |
| `5-more_numbers.c` | Prints 10 times the numbers from 0 to 14 |
| `6-print_line.c` | Draws a straight line in the terminal |
| `7-print_diagonal.c` | Draws a diagonal line in the terminal |
| `8-print_square.c` | Prints a square |
| `9-fizz_buzz.c` | Prints Fizz, Buzz and FizzBuzz from 1 to 100 |
| `10-print_triangle.c` | Prints a triangle |

## Compilation

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 _putchar.c main-file.c function-file.c -o output
